# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub Private Vulnerability
Reporting: open the repository's **Security** tab and choose **Report a vulnerability**.
Do not open a public issue for security problems.

## Supported versions

Only the latest commit on `main` is supported.

## Scope

This policy covers `rmshare` itself, the code in this repository. Problems in
rmfakecloud, the reMarkable tablet software, or the Anthropic API should be reported to
their own maintainers.
